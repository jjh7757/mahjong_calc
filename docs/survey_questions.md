## A. 응답자 (30초)

1. 마작 한 지 얼마나 됐나요? — 6개월 미만 / 6개월~2년 / 2~5년 / 5년 이상
2. 이 매장(또는 오프라인 매장)에 얼마나 자주 오세요? — 오늘 처음 / 한 달에 1번 미만 / 한 달에 1~3번 / 주 1번 이상
3. 주로 어떤 룰로 치세요? — 4인 반장전 / 4인 동풍전 / 3인 / 기타(  )
4. 화료했을 때 점수 계산을 직접 하실 수 있나요? — 부수까지 다 한다 / 판수는 되는데 부수는 막힌다 / 주로 남이 해 준다 / 거의 못 한다

## B. 지금 겪는 불편 — 데모 전에 (1분)

5. 오늘(또는 지난번) 대국에서 화료 뒤 점수 정하느라 판이 멈추거나 의견이 갈린 적이 있었나요? — 거의 매 국 / 반장에 몇 번 / 거의 없음
6. 점수 계산이 막히면 보통 어떻게 하세요? (여러 개) — 잘 아는 사람에게 물어봄 / 점수표·앱 검색 / 사장님께 물어봄 / 대충 정하고 넘어감
7. 점봉 주고받기나 마지막 정산(우마·오카)에서 틀리거나 다시 센 적이 있나요? — 자주 / 가끔 / 없음
8. 대국 결과(국별 점수, 최종 순위)를 기록으로 남기세요? — 안 남김 / 메모·점수판 사진 / 앱·스프레드시트 / 기타(  )
9. 오프라인 대국에서 가장 귀찮은 걸 하나만 고르면? — 부수·점수 계산 / 점봉 주고받기 / 최종 정산 / 기록 남기기 / 딱히 없음

## C. 데모를 보여 준 뒤 (1분)

> 데모 설명 한 줄: "테이블 위 카메라가 화료 때 판을 찍고, 옆 태블릿이 손패를 읽어 점수를 계산해 점수판에 바로 반영합니다. 틀리면 화면에서 고칩니다."

10. 이런 게 테이블에 있으면 쓰시겠어요? — 꼭 쓰겠다 / 있으면 쓴다 / 상관없다 / 안 쓴다 → 안 쓴다면 이유(  )
11. 화료 뒤 결과가 나오기까지 몇 초면 기다릴 만한가요? — 5초 / 10초 / 20초 / 30초 넘어도 괜찮다
12. 결과가 가끔 틀려서 손으로 고쳐야 한다면? — 그래도 쓴다 / 열 번에 한 번 정도면 괜찮다 / 한 번이라도 틀리면 안 쓴다
13. 카메라가 테이블을 찍는 것에 거부감이 있나요? — 전혀 없다 / 손패만 아니면 괜찮다 / 녹화·저장되면 싫다 / 싫다
14. 가장 갖고 싶은 기능 두 개만 고르면? — 점수 자동 계산 / 점수판·최종 정산 자동 / 대국 기록·개인 통계 / 버림패 복기(기보) / 초보 도움(대기패·역 설명)
15. 이 기능이 있는 테이블(매장)을 일부러 고르시겠어요? 추가 요금을 낸다면? — 안 낸다 / 시간당 500원 / 1,000원 / 2,000원 이상
16. 오히려 이게 있으면 불편하거나 싫을 점은? (주관식)

## D. 마무리 (선택)

17. 나중에 시험판을 써 볼 의향이 있으면 연락처(카톡 ID 등)를 남겨 주세요. — 선택 사항, 연락 목적 외에 쓰지 않음

## 사장님 질문 (따로, 대화로)

1. 손님들이 점수 계산 때문에 사장님을 부르거나 판이 늘어지는 일이 얼마나 있나요?
2. 지금 점수 계산·정산·기록에 쓰는 도구가 있나요? (점수표, 자동탁 기능, 앱 등)
3. 테이블에 태블릿·카메라를 다는 데 걸리는 점은? (자리, 전원, 와이파이, 고장·분실, 손님 거부감)
4. 이런 걸 들인다면 어떤 방식이 낫나요? — 한 번 사기 / 월 이용료 / 손님 추가 요금 / 무료면 시험만
5. 얼마면 한 테이블에 달아 볼 만한가요? 먼저 한 테이블에서 시험해 보실 의향은?
6. 매장 이벤트·리그전 기록에 쓸 수 있다면 도움이 될까요?
