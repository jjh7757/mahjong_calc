# 시장 조사와 수요 확인 (2026-10-23)

새 세션이 "비슷한 게 이미 있나", "누가 쓸까" 를 다시 조사하지 않도록 정리한 것. 출처는 각 항목 링크. 정확도·판매 여부는 확인 안 한 것이 많다(표시함).

## 결론

- "손패 촬영 → 점수 계산" 앱은 국내외에 이미 많다. 개인용 앱으로는 이것만으로 차별화가 어렵다.
- 일반 패로 **테이블 전체**를 읽어 리치·방총자·뒷도라까지 판독하고 **대국 기록·정산**까지 하는 상용 제품은 찾지 못했다. 탁자 단위 자동화는 전용 IC 패 탁자(パイリーダー, 2012)나 대학 연구(Projection Mahjong)뿐.
- 그래서 차별점은 "계산" 이 아니라 "기록 자동화" 이고, 대상은 개인보다 **매장·대회·오프라인 방송** 쪽이 유망하다(검증 전 가설).
- 커뮤니티·스트리머 반응은 좋지 않았다(2026-10-23, 설명만 듣고 한 반응). 이유는 **"이미 있다"**(손패 촬영 앱이 많다)였다(2026-10-23 사용자 확인). → 차별점(테이블 전체 판독 + 기록 자동화) 전달이 과제. "필요 없다"·"설치 귀찮다"·"정확할까" 는 나오지 않았다.

## Projection Mahjong (후쿠이대 長谷川 연구실) — 키오스크와 가장 가까움

- 출처: [EC2023 논문(공개, 본문 읽음)](https://ipsj.ixsq.nii.ac.jp/record/227470/files/IPSJ-EC2023023.pdf), [2026 저널(유료, 초록만)](https://link.springer.com/article/10.1007/s11042-026-21151-7)
- 구성: 탁자 바로 위 카메라 + 프로젝터(스피커 내장) + PC. 프로젝터가 자풍·장풍·국·본장·리치봉 자리·점수·연출을 탁자에 투영. 파란 화면 투영 → 카메라로 투영 위치 자동 보정.
- 흐름: 각자 오른쪽 앞 "트리거 영역" 에 **패를 엎어 놓으면 화료 선언**(ResNet18 이진 분류, 250장 100%) → 프로젝터가 손패·울기·화료패·도라 놓을 자리를 비추고 사람이 **옮겨 놓음** → YOLACT 인식(약 3.5초) → Python `mahjong` 라이브러리로 점수 → 연출. 리치봉은 가운데 영역에서 분류 모델, 30fps 5회 연속일 때 인정, 국당 1회만. 일발은 도라 표시패를 눕혀 표시. 유국·종료는 키보드 키. 방총자 결정 방법은 논문에 없음.
- 실험(8명, 동풍전): 점수 확정 시간 손계산 32.0초/13.8초 vs 시스템 28.4초/33.8초 — **재배치·확인·재인식 때문에 빠르지 않았음**. 분위기(대면 대비 p=0.021)·시청각 즐거움은 유의하게 좋음, 원활함·사용성은 유의차 없음. 한계: 패 인식 오류, 강·패산 미인식, 우연역 대부분 미지원. 2026 저널 초록: 손패 인식 99%, 숙련자 손계산이 약 2배 느림(개선판으로 추정).
- 가져올 것: (1) 엎은 패로 화료 신호 → 카메라 헤드 자동 촬영 트리거, (2) 리치봉 N프레임 연속 감지, (3) 패를 옮기게 하지 말 것 — 확인 단계가 남으면 자동화 이점이 사라짐 → 정확도 측정 후 자동 반영, (4) KPI "화료 선언 → 점수 확정 시간" 을 손계산과 비교, (5) 키오스크 화면으로 프로젝터도 선택지(밝은 매장 조명은 미검증).

## 수요 확인 계획 (2026-10-24 토 14:00 이수보드카페유화 방문 때)

카페는 혼자 촬영 목적 이용 가능·요금 안내 받음(2026-10-23). 당일 체크리스트(폰용, 스톱워치 포함): `docs/visit_checklist_1024.html` = https://claude.ai/artifact/KHLWRkLkwTPaHNcpqee6NL

1. 사장님에게 실제 동작 보여 주고 질문: 손님이 점수 계산에서 막히는 일이 자주 있는지 / 테이블에 이런 게 있으면 도움이 될지 / 얼마면 달아 볼지.
2. 화료 선언 → 점수 확정 시간을 손계산과 앱으로 나란히 잰다(Projection Mahjong 기준 손계산 14~32초).
3. 계속할 기준을 미리 정한다(예: 사장님 관심 또는 써 본 손님 5명 중 2명 이상 재사용 의향 → 계속, 아니면 대상을 매장·대회·방송 중 하나로 좁히거나 방향 전환).
4. 부정적 반응은 이유별로 분류: "이미 있다"(차별점 전달) / "필요 없다"(대상 변경) / "설치 귀찮다"(설치 방식) / "정확할까"(실험 결과로 답).
