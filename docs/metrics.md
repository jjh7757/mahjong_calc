# 속도·정확도 변경 이력표

판독 속도·정확도를 바꾼 변경마다 **얼마에서 얼마로** 바뀌었는지 한 줄씩 적는 표. 실험 과정·해석은 `experiments/field_20261024/NOTES.md`(절 번호로 가리킴)에 있고, 여기는 수치만 모은다.

## 규칙 (측정할 때마다)

1. **측정이 끝나면 바로 아래 표에 한 줄 더한다.** NOTES 에 절을 쓰는 것과 별개로, 이 표의 해당 지표 표에도 넣는다. 채택하지 않은 실험도 넣고 "채택" 열에 ✗ 를 적는다.
2. **같은 조건끼리만 비교한다.** 표가 지표·조건별로 나뉘어 있으니 맞는 표에 넣고, 조건(평가 세트·서버·환경·횟수)이 다르면 열에 적는다. 조건이 어느 표에도 안 맞으면 새 표를 만든다.
3. **평가 세트는 B·C·D(사진 6장)** 고정. 매장 사진 15장·A·E 는 규칙을 고치는 데 쓰지 않고 "평가 밖(참고)" 표에만 넣는다(2026-10-27 사용자 결정).
4. 시간은 초, "중앙 / p90 / 최대" 순. 정확도는 "맞은 수/전체". 없는 값은 `—`.
5. 서버 변경이면 커밋 해시(mahjong-recognizer), 앱 변경이면 파일명을 적는다. 운영 배포 뒤 측정은 "운영 <해시>" 로 적는다.
6. 비교 실험은 **같은 시각에 나란히** 돌린 것만 전·후로 적는다(Gemini 지연이 시간대마다 달라서). 시각이 다르면 메모에 적는다.
