## 문제 1: 맞춘 틀 다음 — 기대값 식 그대로 ❌, 언어 모델 에이전트가 버림을 고르게 해도 ❌

- **해결방안:**

  - 까닭: 엔진의 국수지는 텐파이에서만 진짜 기대값이고, 1 · 2샹텐은 거기까지 갈 확률이 안 곱해져 한 걸음 멀어져도 값이 거의 안 줆, 3샹텐 이상은 0. 속도도 식에 없음. 위험 배수를 키우면 2샹텐은 37.3 → 49.3% 로 오르고 텐파이는 69.8 → 49.2% 로 떨어져 배수 하나로는 못 맞춤.
  - 사용자 "계산기는 상황에 따라 계산하기 힘들어도 에이전트는 그런 상황 추론까지 가능하지 않니" → "재 보기". 규격 · 판정 문구 · 채점 스크립트는 답 보기 전에 설계서 `docs/mxplainer_fit_design_1121.md` 13절에. Opus 5.5 하위 에이전트 12개 × 20결정(검증 40판에서 240결정, Claude API 0).

2. 감사는 `subagents/agent-*.jsonl` 의 도구 사용으로 — 12개 모두 자기 문제지 읽기 1 · 답 쓰기 1 · 보고 1뿐(`mxfit/agent_audit.py`).
3. 한계: 240결정 · 지시문 하나 · 한 번, 제품의 Gemini 가 아닌 Opus, 심판 S42. 기대값 식 쪽은 식의 꼴 · 배수를 결과를 보며 바꿔 본 탐색.
