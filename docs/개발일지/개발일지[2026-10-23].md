## 문제 1: 폰 테스트에서 장수가 7장·11장으로 나왔는데 이유를 알 수 없음

- **원인:** 서버 로그에 읽은 패 목록·notes 가 안 남고, 앱도 0장이거나 장수가 틀릴 때 이유를 보여 주지 않음.
- **해결방안:** 서버 로그에 tiles·notes 추가, 앱은 0장이면 notes + 촬영 체크리스트 + "다시 찍기", 장수가 틀리면 이유를 붙인 토스트, 진행 창에 경과 초·취소 버튼. 해결됨(에뮬레이터 확인).

### 시행착오

1. 서버 로그로 10-22 밤 요청 4건 확인 → 13·14장은 4~6초로 정상, 7·11장은 무엇을 읽었는지 확인할 수 없었음.
2. 같은 phone_shot1 을 다시 넣음 → 이번엔 5초 만에 0장(10-22 엔 63초). 지연 편차가 큼.

## 문제 2: 게임 화면으로 2단계 흐름을 돌리니 화료패를 엉뚱하게 잡음

- **원인:** 손패 크롭 여백 15% 에 옆자리 버림패가 들어옴. 울기도 모양이 틀린 답(연속이 아닌 치)이 그대로 나옴.
- **해결방안:** 여백 15% → 4% + 프롬프트에 "같은 줄 바로 옆", 서버에 울기 정합성 검사(틀린 울기는 버리지 않고 확신도 0 → 앱이 노란 테두리로 물음). 해결됨.

### 시행착오

1. 1차(작혼 계열 리플레이 화면) → locate 6.8 + 읽기 18.2 = 24.9초. 아래 손패(90px) 10/10, 화료패는 옆 버림패 4만을 잡음.
2. 2차(여백·문구 수정) → 14.9초, 화료패 문제 사라짐. 45~60px 인 오른쪽 손패·원근 울기는 두 번 결과가 다름 → 100px 기준을 다시 확인함.
