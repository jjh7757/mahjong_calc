2. 테스트 15장 펴기 없이 → 손패 0 → 6/15, 방총자 0 → 10/15, 패 155 → 201/211. 펴기 경로(198)보다 높고 펴기 3초도 없음.
3. 미리 적은 기준으로 판정 → 경고 없는 틀린 자동 0 → 3 으로 미채택. 세 건을 뜯어보니 모두 F1400 → 위 원인으로 조건부 채택.
