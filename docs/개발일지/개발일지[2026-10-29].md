# 개발일지(2026-10-29)

## 문제 1: 판독 구역 격자를 카메라 놓을 때마다 손으로 맞춰야 함

- **원인:** 격자 선 4개를 사람이 끌어 맞추는 구조였음. 자동으로 잡으려 해도 선이 연출로 놓인 도라 표시패를 가르거나, 기운 탁자를 못 나눔.
- **해결방안:** 서버 `/v2/setup` 이 손패·울기·기기 틀을 주면 앱이 "손패 바깥 띠 4개 + 리치봉 상자 + 나머지" 구조로 격자를 제안함. 대국 시작 직후 한 번 자동으로 맞춤(운영 0040afb, 앱 dbddb8b·558807e). 해결됨(매장 확인 전).

### 시행착오

1. Gemini 가 전경에서 격자 선 4개를 바로 그리게 함 → 먼 자리 B 가 1/6·2/6. 미채택.
2. Gemini 손패 틀에 딱 맞춘 격자 → 틀린 자동 반영 2. D 의 선이 가운데 도라 표시패를 잘라 4통만 읽음.
3. YOLO26 자동 격자 + 넉넉한 규칙 → B·C·D 는 6/6 나오지만 기운 합성 사진은 선 4개로 못 나눔. 미채택.
4. 사용자 그림 구조(바깥 띠 4개 + 리치봉 상자)로 바꿈 → 점수 8/12, 틀린 자동 4. D 의 연출 도라가 오른쪽 띠 선에 걸림.
5. 도라 안전 규칙을 넣음: 왕패 상자·리치 손패 옆이 아닌 곳에서 읽은 도라는 자동 반영 안 함 → 틀린 자동 0.
6. 가운데 칸 도라 크롭을 화료자 아닌 쪽으로 40 넓힘 → 점수 12/12.
7. 매장 삼각대 15장(평가 밖)에 자동 맞추기 → 7/15, 기울기만큼 돌리면 9/15. 사용자 결정: 기울기 보정은 더 만들지 않고 카메라를 위에서 반듯하게 거치함.
8. 앱 안 자동 맞추기 흐름 → 격자 원본 5/6, 점수 원본 6/6·왕패 합성 6/6.

## 문제 2: 리치 아닌 화료의 도라 표시패를 어디서 읽나

- **원인:** 도라는 왕패(도라 산)에 있는데, 위치는 주사위로 정해져서 선(친)만으로는 알 수 없음. 가진 사진은 전부 판 끝 장면이라 판 시작 왕패가 없었음.
- **해결방안:** 판 시작(새 판 첫 버림) 때 `/v2/wall` 로 왕패 상자를 한 번 잡고, 리치 아닌 화료면 그 상자만 `/v2/walldora` 로 읽음. 해결됨(매장 확인 전).

### 시행착오

1. 선(친) 앞 패산에 도라 구역 상자 → 최종 도라는 같았지만 B·C·D 는 왕패가 한 곳에 고정이라 확인할 수 없어 보류.
2. 처음엔 도라 표시패 묶음을 찾음 → 4/6. 사용자 지적으로 목표를 "도라 산"으로 바꿈.
3. 왕패 상자 찾기 → 16/18. 공간 인식 모델(robotics-er)은 6/18로 나빴음.
4. 블로그에서 본 규칙(7줄·ㄱ자·3번째 줄)을 넣은 1안 → 생각이 늘고 14/18. 화료 뒤 도라를 옮긴 왕패를 "특정 불가"로 버림.
5. "쓸데없는 것 넣지 말 것" 지시대로 판 시작 전용 문구로 바꾸고, 왕패에 七萬 을 붙인 합성으로 잼 → 14/18.
6. "일자 7줄"로 좁힘 → 합성 패산이 꺾여 있어 0/18.
7. "도라 있는 변의 일자 구간, 이웃 변 줄은 넣지 않음"으로 고침 → 17/18, 도라 읽기 17/18.

## 문제 3: 매장 리치봉(파란 막대)을 추적이 못 잡음

- **원인:** 처음엔 흰 봉을 가정했음. 매장 리치봉은 기기 홈에 꽂는 파란 막대라 넓은 띠의 평균 밝기 차로는 묽어짐.
- **해결방안:** 크게 바뀐 블록 비율(≥ 0.06)을 더하고 리치봉 추적을 다시 기본 켬. 리치 시점으로 일발·더블리치 후보까지 추론함(f4debc6). 해결됨(합성·태블릿까지, 실제 봉은 매장에서).

### 시행착오

1. 가는 흰 막대 합성 → 못 잡음. 실제 크기 흰 막대 → 상자 격자에선 잡히지만 헛 강 버림 2.
2. 사용자 지적: 장면 D 는 격자 가운데가 기기 중심보다 아래라 막대가 홈을 벗어남. 홈 안에 넣어도 흰 봉은 강 버림으로 잡힘.
3. 파란 막대로 바꿈 → 헛 버림은 사라졌지만 평균 차 0.008~0.018로 못 잡음.
4. 바뀐 블록 비율 문턱을 더함 → 리치 확정·리치 시점·일발 후보 맞음, 헛 버림 0. 리치봉 상자가 없는 기본 격자에선 여전히 못 잡음.
5. 태블릿 실기기 흐름 → 추적 전부터 꽂혀 있던 봉을 리치로 적는 문제를 고친 뒤 일발 후보가 오른쪽만 남음(정답).
