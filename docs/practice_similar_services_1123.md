## 우리 아이디어와 비교

- **"상대 강을 보고 대기를 맞힌다" 는 이미 있다.** 何待ち？가 가장 가깝다. 출시 연도 · 버전 기록으로 보아 2026년 앱이고, 평가 5개로 아직 작다. 따라서 "세계 첫" 이라고 말하면 안 된다.
- **아직 못 본 것(우리 차별점 후보):**
  1. **실제 쏘인 비율 · 실제 손패로 채점하고, 순서 지표(Mizukami 0.502 ~ 0.744)로 실력을 숫자로 냄** — 찾은 서비스는 정답/오답이나 AI 일치율만.
  2. **효과 측정** — 어느 서비스도 연습 전후 실력 변화를 재지 않음(논문 쪽도 계획만).
  3. **리파이 읽기(버린 칸 위치)** — 온라인 패보에는 칸 위치가 없어서 다룬 곳이 없음. 단 우리 실험에서도 이득이 작음(표 17-2 · 17-4 "사이").
  4. **자기가 직접 친 오프라인 대국을 문제로** — NAGA 는 온라인 천봉 패보만.
- **조심할 것:** 위험 % 실시간 표시(mahjong-helper · Majsoul Helper)는 부정행위 도구 쪽이다. 우리는 복기 · 연습으로만 둔다.
- NAGA 역재생 리포트의 "있을 수 없는 손패 거르기" 는 우리 상대 손패 추정과 겹친다. 확률 분포를 주는지는 매뉴얼 본문이 없어 확인 못 함.
