# replay2 · compare — 판정 v2 를 가지로 굴리는 계산기 (2026-11-16)

입력은 `JUDGE.md` 의 판정 형식 v2(구간마다 사건 목록 `draw / discard / place / move / shuffle / call / reveal / unknown`).
v1 `replay.py`(옛 형식)와 따로 둔다 — `replay.py` 의 `norm`·`sort_scheme`·`key` 만 import 해서 쓴다.

```
cd experiments/paifu_frames/handtrack
python -X utf8 replay2.py <판 id> <판정 파일…> [--out 폴더] [--use-rules] [--name 이름]
python -X utf8 replay2.py --selftest
python -X utf8 compare.py <판 id> --a <파일…> --b <파일…> [--out 폴더] [--name 이름]
```

- 판정 파일 여러 개(구간을 나눠 맡은 몫)를 합쳐 읽는다. 같은 구간이 두 번 나오면 멈춘다.
- 결과는 `--out` 이 없으면 `results/handtrack/<판>/replay2_<이름>.json·.txt`(`--use-rules` 면 이름 끝에 `_rules`), `compare_<이름>.json·.txt`. 시험 때는 `--out` 을 줄 것.
- 가짜 판정(칸 값은 아무렇게나, 결과 손패는 의미 없음): `examples/v2_r18_plain_a.json`+`v2_r18_plain_b.json`(후보 없음, 두 파일로 나눔),
  `v2_r18_cands.json`(place 후보 3 · 끝 가림 · shuffle · 리치 뒤 손에서 냄 · 리치 뒤 후보 [7, D]), `v2_n03_call.json`(퐁), `v2_n03_unknown.json`(unknown 끊김 · place·move 후보).

## 구간마다 사건 정하기

| 경우 | 처리 |
| --- | --- |
| 판정 있음 | 그 `events` |
| 판정 없음 · `max_skin < 0.003` · 강 새 패 없음 | 사건 없음 |
| 판정 없음 · `max_skin < 0.003` · 강 새 패 있음 | 새 패마다 `[draw, discard "D"]`(자동, txt 에 `(자동)`). 이미 D 가 있으면 뽑기 없이 그 D 를 버린 것으로 |
| 판정 없음 · `max_skin ≥ 0.003` | **오류** + `unknown`(끊김)으로 처리 |

## 굴리기

- 상태 = R(번호 목록, 칸 순서) + D(번호 또는 없음). 시작 R = 1..n0(n0 = `game.json` 의 `start_tiles` → 판정 파일 `start_tiles` → 13). `draw` 마다 새 번호.
- 사건은 JUDGE.md 뜻 그대로:
  `discard "D"` = D 를 버림 · `discard k` = R 의 k칸을 버림(D 는 그대로) · `place p` = D 를 넣은 뒤 줄의 p칸 · `move f→t` = 빼기 전 f칸을 뺀 뒤 줄의 t칸에 ·
  `shuffle S` = S 칸들끼리 모든 순서 · `call meld_pos` = 그 칸들이 울기로 나감 · `reveal` = 공개.
- **가지:** 칸이 후보 목록이면 후보마다 가지. `end_hidden` 인 `discard "D"` 는 (가) D 를 버림 (나) R 의 마지막 칸 패를 버리고 D 가 그 칸에 섬.
  `shuffle` 은 |S| ≤ 4 면 순열(최대 24), 넘으면 끊김. `call` 의 울기 패 종류 붙이기가 두 가지 이상이면(치·가져온 패 모름) 그것도 가지.
- 같은 상태 + 같은 기록인 가지는 합친다(예: 같은 칸 shuffle 두 번 → 여전히 6가지). 상한 200,000 — 넘으면 그 사건 위치를 적고 판 상태 = "가지 넘침"(차례 결과 없음).
- 사건이 안 맞는 가지는 사라진다(D 없는데 `discard "D"`·`place`, 칸이 줄 밖, D 가 남은 채 `draw`). 일부만 사라지면 경고, **모두 사라지면 오류**를 적고
  `draw` 는 남은 D 를 줄 끝에 넣은 것으로, 나머지 사건은 건너뛴다(버림이면 그 강 패는 5장 셈에만 넣음).
- `discard` 후보에 `"D"` 가 섞인 차례(`what: [12, "D"]`)의 `place` 는, D 를 버린 가지에서는 할 일이 없으므로 그대로 둔다(그 가지의 들어간 칸 = "없음").
- 장수: 구간 시작·끝에서 R 장수를 `n_before`·`n_after` 와 비교. 가지마다 장수가 다르고 일부가 맞으면 안 맞는 가지를 버림("중간에 장수로 버림"),
  아무 가지도 안 맞으면 **"장수 모순" 오류만 적고 계속**(v1 과 같게 — 끊지 않음).
- `d_at_start: true` 인데 앞에서 D 가 없으면 뽑기를 넣는다(txt `(넣음)`, 경고). 끊김 뒤 D 없이 `discard "D"`·`place` 가 나와도 같다.
- `reveal` 뒤 사건·구간은 무시(경고). `reveal` 이 없으면 마지막 상태에서 공개(경고).

## 종류 붙이기

- **버림:** `index.json` 구간별 `river_new` 를 구간 순서대로 이은 강 순서의 k번째(버림 사건 + 끊김이 삼킨 버림을 시간순으로 센 k).
  구간 안 버림 사건 수(+끊김이 삼킨 수) ≠ 그 구간 `river_new` 수면 "버림 수 불일치" 오류를 적고 그대로 전체 k번째로 맞춘다.
  판 구간 전 버림(n03 의 3z·9m = `river_before_ready`)은 `index.json` 구간 밖이라 강 순서에 안 들어간다 — 5장 셈에만 넣는다.
  울려 간 화료자 버림(n03 2z·6p)은 놓였던 구간의 `river_new` 에 있으므로 그대로 버림으로 센다.
- **울기:** `final_hand.melds` 를 3장씩 묶고 `meld_detail` 에서 가로 놓인 1장(가져온 패)을 뺀 2장이 화료자 몫. 그 2장을 `meld_pos` 칸(왼쪽부터)에
  붙이는 모든 순서가 후보(퐁이면 한 가지). 가로 패를 못 찾으면 3장 중 2장 조합 전부. 울기가 여럿이면 call 순서 = 묶음 순서로 가정(경고).
  판정에 `meld_tiles` 가 있으면 그것을 쓴다(v1 호환).
- **공개:** R 의 번호 ↔ `final_hand.closed`(자리 순서). 쯔모(`result` 가 `tsumo` 로 시작, "tsumo?" 포함)면 D = `win_tile`.
  쯔모인데 D 가 없거나 론인데 D 가 있으면 오류(그 패는 종류 ?). `order_kept: false` 면 "공개 순서 불확실" 표시만 하고 읽은 순서를 쓴다.
  줄 장수 ≠ 끝 손패 장수면 끝 손패를 붙이지 못함(오류).
- **끊김**(`unknown`, |S|>4 shuffle, 판정 없음): 그 구간의 강 새 패 중 판정 버림이 안 가져간 만큼(또는 사건의 `discards`)을 끊김이 삼킨다.
  새 덩어리 B, C, … 를 새 번호로 시작(장수 = `n_after` 에서 뒤 사건의 증감을 거꾸로 뺀 값, 없으면 지금 장수). 마지막 덩어리만 끝 손패로 채워지고,
  앞 덩어리의 번호는 버림으로 나간 것만 종류를 안다(나머지 `?`).

## 불가능한 가지 버리기

- **같은 패 5장 이상**(적5 = 5): 화료자 번호 전체(손패·버림·울기) + 판 구간 전 버림 + 끊김이 삼킨 버림. 모든 가지가 걸리면 자료 오류로 보고 버리지 않는다(오류).
  참고: 이 모형에서는 모든 번호가 정확히 한 번 종류를 받으므로 이 셈은 가지와 상관없이 같다 — 실제로는 강·공개 읽기 오류 검사로만 작동한다.
- `--use-rules` 면 더: 리치 선언(강 순서에서 처음 가로 놓인 버림) 뒤의 버림은 D, 울기 직후의 첫 버림은 R 의 패.
  검사점마다 따로 적용하며, 그 검사점에서 **모든 가지가 어긋나면 버리지 않고** "판정이 규칙과 다름" 오류만 적는다(한 판정 실수가 다른 검사점의 가지 버리기를 막지 않게).

## 출력

- 차례 = `draw`(또는 `call`)부터 다음 `draw`/`call` 까지. 차례마다 **뽑기(울기) 직전 R 의 n장**을 손패로 보고:
  서로 다른 손패 수, **확정 장수**(모든 가지 손패 multiset 의 교집합, `?` 제외), 불확정 후보(서로 다른 손패 ≤ 6 이면 교집합을 뺀 나머지를 다 적음),
  뽑은 패 종류(후보), 버린 패(강, `*` = 리치 뒤)와 쯔모기리 / 손에서 냄 / 둘 다, 나간 칸·들어간 칸(가지들에서 나온 값 그대로), 판정 사건.
  시작 손패(덩어리마다)도 같은 셈.
- 판 요약: 차례 수, 쯔모기리/손에서 냄이 정해진 차례 수, 손에서 냄 중 나간 칸·들어간 칸이 한 칸인 수, 끝 가림·shuffle·끊김 수,
  가지 수(규칙·5장으로 버리기 전 → 후, 중간에 장수로 버린 수, 사건이 안 맞아 사라진 수), 손패 완전 확정 차례 수 / 차례 수, 확정 장수 평균·최소,
  시작 손패 확정 장수·후보 수, 오류·경고.
- 규칙 사건 대조(판정 그대로, 가지 버리기 전): 리치 뒤 버림 n건을 판정 종류별(`D` / `D(끝가림)` / `R` / `후보`), 울기 직후 버림 n건도 같게,
  검사점마다 어긋난 가지 수.
- 정렬 점수(참고용, 가지를 버리지 않음): 끝 손패에서 무늬 묶음 순서·숫자 방향을 읽고(v1 `sort_scheme`), 가지마다 모든 차례 손패의 이웃 쌍 중
  정렬과 맞는 비율. 최고·최저·평균, 최고 점수 가지만 남겼을 때의 요약.
- txt 한 줄: `순 · 구간 · 뽑음 · 버림(쯔모기리/손에서 k칸) · 들어간 칸 · 뽑기 전 손패(확정 + ?{후보}) · 확정 n/n(가지 수) · [판정]`.
  "버리기 전 손패" 대신 뽑기 전 n장을 적는다 — 버리기 전 n+1장 = 이 손패 + 뽑음 칸.

알아 둘 것: 차례 t 의 손패 multiset = 끝 손패 + t 뒤의 버림·울기 몫 − t 뒤에 뽑은 패. 버림·울기·끝 손패 종류는 가지와 상관없으므로,
손패가 갈리는 것은 **t 뒤에 뽑은 패의 운명**(끝에 어느 칸에 섰나, 또는 몇 번째 버림이 되었나)이 가지마다 다를 때뿐이다.
그래서 R 칸끼리의 후보는 그 칸들에 뒤에 뽑은 패가 없으면 손패를 바꾸지 않고, place 후보·D/R 후보·끝 가림은 거의 늘 바꾼다.

## compare.py

구간마다(판정 없는 구간은 위와 같게 채움, 손이 들어왔는데 판정 없음 = "판정 없음"):
- **확정 일치** = 사건 종류 순서가 같고, 모든 칸이 한 값이며 서로 같고, `end_hidden`·`shuffle`·`unknown` 이 없음.
- 느슨한 일치: 종류 순서 같음 / 버림이 D 인지 R 인지 같음(끝 가림 = D·R 둘 다) / 버린 칸(후보 집합, 끝 가림 표시 포함) 같음 /
  들어간 칸(place 후보 집합) 같음 / 후보 집합이 겹침(종류 순서가 같고 대응하는 칸마다 후보가 하나 이상 같음).
- 분모 = 화료자 차례가 있는 구간(둘 중 하나라도 draw·discard·call, 또는 한쪽이 판정 없음). 다른 구간은 두 판정을 나란히 적는다.
- 판 단위 "끊김 0" = 분모의 모든 구간이 확정 일치. 분모 밖(move·shuffle 만 있는 구간)에서 다른 것도 따로 적는다.
- `left`·`right`·`conf`·`note`·`n_before`·`n_after`·`d_at_start` 는 비교하지 않는다.

## 자체 시험 (`--selftest`, 손 계산과 대조)

1. 손패 4장 · 버림 3번 · place 후보 [3,4] 1번 → 가지 2, 시작 확정 3(후보 3s|4s), 차례별 확정 [3,4,4,4], 1순 뽑음 {3s,4s}, 완전 확정 3/4, 평균 3.75, 정렬 8/10(두 가지 같음).
2. 끝 가림(2장, 론) → 가지 2, 시작 확정 1, 뽑음 {9m,2p}, 쯔모기리|손에서 2칸, 들어간 칸 2|없음.
3. 리치 뒤 [2, D] 후보 → 규칙 끔 가지 2(시작 확정 2), 켬 가지 1(시작 확정 3). 리치 뒤 손에서 낸 판정은 모든 가지 위반 → 버리지 않고 오류.
4. shuffle 3칸 → 6가지(손패 하나), 같은 칸 두 번 → 그대로 6가지.
5. 같은 패 5장(모든 가지) → 버리지 않고 오류.
6. 퐁(가로 패 = 셋째) + 울기 직후 버림 → 가지 1, 시작 확정 5, 울기 직후 버림 R 1건, 차례 (draw 5)(call 5)(draw 2).
7. unknown 끊김 → 덩어리 2, 사이 버림 [6z], 덩어리별 시작 확정 [1, 2], 1순 확정 1 + ?1.
8. 자동 처리(손 없는 구간 강 새 패 → 자동 쯔모기리, 손 있는데 판정 없음 → 오류·끊김).
9. 가지 넘침(상한 50 으로 낮춰 64가지) → 구간 3 에서 "가지 넘침".

## 한계·정하지 않은 것

- 깡(4장·영상 보충패)은 다루지 않는다 → 판정자가 `unknown`. 울기 여럿은 순서 가정.
- 쯔모인데 화료패를 줄에 넣고 공개(`place` 뒤 `reveal`)하면 장수가 1 많아 끝 손패를 못 붙인다(오류).
- 가지 9만 개에 약 25초(가지마다 기록을 두 번 펼침). 상한 20만이면 1분 안팎.
- 끊김이 있으면 앞 덩어리의 손패는 `?` 가 섞여 확정 장수가 낮게 나온다(설계대로).
