# 흔들기 회귀 세트 (개선 계획 3단계, `docs/improvement_plan_1105.md`)

다른 카메라·조명·탁자를 새 사진 없이 흉내 내어 "나빠짐" 을 잡는 안전망이다. **맞추는 대상이 아니다** — 변형별 결과는 어느 조건이 약한지
알려 주는 진단이고, 그 조건을 겨냥해 서버 규칙·문턱을 고치는 근거로 쓰지 않는다(고치려면 7단계 합성 학습으로).

스크립트: `experiments/speed/robust_suite.py`(make · felt · run · report). 변형 사진은 `experiments/speed/robust/<변형>/<사진>.jpg`(커밋 안 함).

## 대상

개발 장면 = `seat_grow.eval_scenes()` = EXCLUDED 5장을 뺀 **사진 26장**(B·C·D 6 + 매장 20). B·C·D 는 앱 흐름 기준선(REPEAT=2)처럼
무게 2 로 세어 **/32 회**로 적는다(표 1-90 과 같은 분모). 서버는 같은 입력에 같은 답이라 두 번 돌리지 않는다.

## 격자 처리

- 밝기·흐림·JPEG·화이트밸런스·가림·재색칠: 픽셀만 바뀌므로 **저장 격자 그대로**.
- 축소: 0~1000 정규화 격자라 **그대로**.
- 회전: **(b) 앱의 펠트 격자로 다시 잡는다** — 앱의 갤러리·태블릿 경로가 `feltQuadOfJpeg` → `gridFromFelt` 로 격자를 잡으므로 실제 앱과 같다
  (`tool/robust_felt_grid_test.dart`). 펠트를 못 찾으면 (a) 변환 행렬로 저장 격자 네 꼭짓점·리치봉 상자를 옮긴 감싸는 축 상자로 읽고 `grid_src=a` 로 표시해 따로 센다.
  펠트 격자 몫과 회전 몫을 떼려고 `felt0`(원본 + 펠트 격자)을 대조로 같이 잰다 — 회전의 효과는 `felt0` 대비로 읽는다.
  회전은 캔버스를 넓혀(빈 곳 회색 114) 내용을 잃지 않는다. 서버 `prepare_image` 가 긴 변 4080 으로 줄이므로 ±25° 는 실효 축소 약 0.82 가 겹친다.
- 원근(기울기)은 이번 목록에 없다(테스트 15장이 그 조건 — 1단계 펴기로 따로 잼).

## 채점

서버 단독, 서버 코드 `app.roles.read_roles(hybrid)` 를 프로세스 안에서 그대로 부른다(`/v2/localroles` 와 같은 경로, 사진은 서버처럼 `prepare_image(4080)` 거침).
모델 조합 두 벌:

- `fold`: 그 사진을 안 배운 모델(대응표 `experiments/tile_classifier/README.md` 끝 절 — launch.json `recognizer-fold-*` 와 같은 파일).
- `prod`: 운영과 같은 모델(서버 assets, 개발 사진을 전부 배움).

지표(사진별, B·C·D 무게 2):

- **장면 맞음** — 손패(+떼어 둔 패)와 울기가 정답과 같음(`role_full_bench.judge`, 자리 채점).
- **패 단위** — 손패+떼어 둔 패+울기 다중집합 교집합 / 정답 장수.
- **unsafe(검사 통과했는데 틀림)** — 화료형·텐파이 검사(`hybrid.check`)는 통과했는데 틀림. 서버 `block` 은 안 봄.
- **틀린 자동 반영** — unsafe 이면서 서버 `block` 도 없음(앱이 경고 없이 넣을 후보, `role_full_bench` 의 hybrid 틀림과 같은 정의).

## 합격 기준(변경을 채택할 때마다, 계획서 3단계)

회귀 세트에서 unsafe·틀린 자동 반영이 **늘지 않음**, 패 단위가 기준 −2% 이내. 변경 전후는 같은 시각에 연달아 돌린다.

## 세기 조정 규칙

기준선(fold·prod)을 한 번 돌려, 어떤 변형 **묶음**(회전·축소·흐림·노출·화이트밸런스·JPEG·가림)의 모든 세기에서 두 모델 조합 모두
"추가 실패 0"(`orig` 에서 맞은 사진이 하나도 안 틀려지고 패 단위도 안 줄어듦)이면 판별력이 없는 것으로 보고, 그 묶음만 아래 미리 정한
한 단계 센 수준을 **한 번만** 더해 다시 돌린 뒤 고정한다. 후보 모델을 보고 세기를 고르지 않는다.

미리 정한 한 단계 센 수준(작업 시작 전에 적음): 회전 ±35° · 축소 0.45 · 흐림 σ 5px · 노출 ±1.5EV · 전구색 (1.45, 1.0, 0.45)·형광등 (0.85, 1.18, 0.90) ·
JPEG q35 · 가림 3~4개. 재색칠은 색이 범주라 센 수준이 없다(판별력 없으면 그대로 적음).

고정 기록은 아래 줄에.

고정(2026-11-05 22:00, 기준선 metrics 표 1-91): 두 모델 모두 추가 실패 0 이었던 묶음은 JPEG(q60) 하나 → 미리 적은 q35 를 한 번 더해(fold 새 실패 2) **`jpeg35` 로 바꿔 고정**.
나머지는 첫 세기 그대로. 고정 세트 = `orig`·`felt0`·`rot_{p,m}{3,10,25}`·`scale08`·`scale06`·`blur1`·`blur2`·`ev_p1`·`ev_m1`·`wb_tung`·`wb_fluo`·`jpeg35`·`hand`·`rc_gray`·`rc_dgreen`·`rc_redframe`
(21개, `jpeg60` 은 기록으로만 남김). 이후 세기를 바꾸지 않는다.

만든 뒤 확인한 것: 패 높이(긴 변)는 원본에서 약 105~150px(B·C·D 113~153, 매장 104~117) — 축소 0.6 이면 65~90px, 흐림 σ3 은 패 높이의 2~3%.
`rc_redframe` 은 매장·B·C·D 테두리가 흰색이라 마스크가 잘 잡힘(사진의 약 10%). `rc_dgreen` 은 매장 펠트가 원래 짙은 초록이라 차이가 작은 약한 변형이다.
펠트 격자는 182장 중 174장 잡힘 — 171245 는 원본부터 못 잡고(회전 전부 (a) 로), 134815 −25° 하나.
