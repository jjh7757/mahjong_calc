계산기

입력 화면
팔레트로 손패·도라·뒷도라를 넣는 기본 화면. 사진 입력·부르기 버튼, 위 아이콘은 대국·비우기·더보기.
상황 입력
론/쯔모·자풍·장풍·리치·일발·해저·영상개화·창깡·천화·본장. 대국 중이면 '누구 손패?' 자리 선택이 위에 붙고 점수판 값이 채워진다.
손패 13장
13장이면 아래 버튼이 '대기패 보기'로 바뀐다. 14장이 차면 도라 표시패 탭으로 자동 이동.
대기패 시트
대기패마다 론·쯔모 점수. 줄을 누르면 그 패로 바로 결과 화면.
부르기 시트
치·퐁·깡·안깡을 고르고 패를 누르면 묶음 추가. 적도라 5 포함 체크.
결과 화면
손패 → 역 한 줄씩 → 판·부 + 등급 도장 → 점수. 아래 '점수 이동' 십자판(대국 중이면 자리 배치·변화·공탁). '대국에 반영' 버튼.
더보기 메뉴
거치 촬영 / 카메라 헤드 / 점수표 / 점수 계산 연습 / 룰 설정.

대국 기록

대국 시작 (위)
자리 순서·이름, 시작점·반환점·우마·반장/동풍·반올림·동시 론.
대국 시작 (아래)
서입(연장전)·아가리야메·텐파이야메 토글, 중간부터 기록 시작.
점수판
국·공탁·점수, 화료/리치/유국/정산/취소 버튼, 아래에 사건 기록.
화료 시트
화료자·론/쯔모·방총자·판/부 또는 역만·함께 론한 사람(더블론)·리치봉 자동 반영·지불 미리보기.
화료 시트 — 파오
역만(대삼원·대사희)이면 '파오(책임지불)' 칩. 쯔모 전액·론 절반.
유국 창
도중 유국(구종구패·사풍연타·사깡산료·사가리치) / 텐파이한 사람 + 리치 / 유국만관.
유국 창 — 도중 유국 선택
사유를 고르면 텐파이 선택이 숨고 점수 이동 없이 친 유지·본장 +1.
점수판 — 토비
점수가 0 미만이면 배너와 정산만 남는다.
점수판 — 아가리야메
올라스에 친이 1위(반환점 이상)로 화료하면 자동 종료.
점수판 — 대국 종료
올라스 뒤 1위가 반환점 이상이면 종료(아니면 서입).
정산
순위·점수·우마/오카 반영 최종값, '저장하고 종료'.
지난 대국
저장한 대국 목록(비어 있을 때).
